# دليل المنشآت الغذائية

تطبيق ويب ثابت باللغة العربية، جاهز للنشر على Netlify. يبحث في الأنشطة الواردة في الملف، ويعرض الاشتراطات العامة والخاصة والممارسات والإجراءات التشغيلية لكل نشاط. يمكن اختيار نشاط واحد، وتحديد الأقسام المطلوبة، ثم تنزيلها في ملف PDF أو فتح محادثة واتساب.

## النشر على Netlify

1. ارفع محتويات هذا المجلد أو ملف `netlify-app.zip` إلى Netlify Drop، أو اربط المجلد بمستودع Git.
2. إعدادات البناء المضمنة جاهزة: لا يلزم أمر بناء، ومجلد النشر هو جذر المشروع (`.`).

## مشاركة PDF عبر واتساب

على الكمبيوتر، يفتح التطبيق المحادثة ويُنزل ملف PDF؛ أرفق الملف في المحادثة واضغط إرسال. على الهاتف، جهّز الملف أولًا ثم اضغط زر المشاركة مرة ثانية لفتح قائمة المشاركة واختيار واتساب والمستلِم. يمكن أيضًا فتح المحادثة بالرقم وإرفاق الملف يدويًا.

## ملاحظة عن النص

النصوص منقولة من المستند المصدر باستخدام OCR؛ لذلك قد تظهر أخطاء تعرف ضوئي، خصوصًا في الأرقام والجداول. يُستحسن مراجعة النص مقابل النسخة الرسمية قبل استخدامه للترخيص أو الامتثال.
