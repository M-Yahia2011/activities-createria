# دليل اشتراطات الأنشطة

تطبيق ويب ثابت باللغة العربية، جاهز للنشر على Netlify. يبحث في الأنشطة الواردة في الملفات المصدرية، ويعرض الاشتراطات العامة والخاصة والممارسات والإجراءات التشغيلية لكل نشاط. يبدأ من دون نشاط محدد، وبعد اختيار النشاط يتيح مشاركة ملف PDF الكامل.

ملفات PDF الكاملة للأنشطة موجودة في `pdfs/`، وتُنشر كملفات ثابتة مع الموقع. يحمل التطبيق ملف النشاط مباشرة من Netlify، ولا يولّد ملفات PDF في المتصفح. أضيفت ثلاثة أنشطة لمغاسل الملابس، وتعرض ملفات الملحق رقم (4) كاملة عند مشاركة أي من أنشطة المغسلة.

### توليد ملفات PDF

على macOS، ثبّت التبعيات في بيئة افتراضية ثم شغّل المولّد:

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r scripts/requirements.txt
python3 scripts/build_pdfs.py
```

لتوليد ملف نشاط واحد فقط: `python3 scripts/build_pdfs.py <activity-id>`. يتطلب المولّد خط Arial المرفق بالنظام في `/System/Library/Fonts/Supplemental/Arial.ttf`.

ملفات أنشطة المغاسل الثلاثة، بما فيها صيغتا ترميز Unicode لاسم ملف الغسيل الآلي، وملفات الصالونات الأصلية محفوظة كما هي. يتخطّى المولّد أيضًا أي نشاط يستخدم `documentOnly` أو يحدد ملفًا جاهزًا في `pdfFile`. اختيار أحد هذه الأنشطة صراحةً لن يكتب أي ملف.

لتشغيل اختبارات الحماية: `python3 -m unittest discover -s scripts -p 'test_*.py'`.

## النشر على Netlify

1. ارفع محتويات هذا المجلد أو ملف `netlify-app.zip` إلى Netlify Drop، أو اربط المجلد بمستودع Git.
2. إعدادات البناء المضمنة جاهزة: لا يلزم أمر بناء، ومجلد النشر هو جذر المشروع (`.`).

## مشاركة PDF

زر مشاركة الملف يفتح قائمة المشاركة على الهاتف (وقد يحتاج ضغطة ثانية إذا لم يكتمل تحميل الملف بعد اختيار النشاط). على الأجهزة التي لا تدعم مشاركة الملفات، يُنزّل الملف لمشاركته من التنزيلات.

## ملاحظة عن النص

النصوص منقولة من المستند المصدر باستخدام OCR؛ لذلك قد تظهر أخطاء تعرف ضوئي، خصوصًا في الأرقام والجداول. يُستحسن مراجعة النص مقابل النسخة الرسمية قبل استخدامه للترخيص أو الامتثال.
